# PostgreSQL vs MySQL

|항목|PostgreSQL|MySQL|
|--|--|--|
|철학|표준 SQL + 기능 확장(정확성)|속도와 단순성(웹 중심)|
|ACID 준수| 매우 엄격함|기본 InnoDB 엔진에서 지원, 일부 제한|
|트랜잭션|고급 트랜잭션 처리, MVCC 강력|InnoDB 기준 기본 제공|
|복잡한 쿼리|윈도우 함수, CTE, 재귀 쿼리, JSONB등 풍부|기본 쿼리는 충분하나 복잡한 기능 제한|
|확장성|사용자 정의 함수/타입/인덱스|커스터마이징 제한|
|JSON 지원|JSONB로 Indexing 및 쿼리 속도 우수|JSON 지원은 있지만 단순 저장용|
|지리정보(GIS)|PostGIS로 강력한 공간정보 처리|기본 제공은 약하고 외부 확장 필요|
|속도|복잡한 쿼리는 느릴 수 있음|단순 SELECT 쿼리 속도 빠름|
|커뮤니티와 문서|개발자 중심, 논문 수준 문서도 많음|사용자 많고 실무 예시 많음|
|트리거/스토어드프로시저|정교한 로직 처리 가능|상대적으로 단순, 제약 많음|
|사용처|금융, 데이터 분석, GIS, ERP 등| 웹서비스, CMS, 쇼핑몰 등|
### PostgreSQL가 나은 점
- 표준 SQL와 확장성
- 정밀한 트랜잭션 처리
- NoSQL + RDB 통합
- 오픈소스 기반 기업용 DB로 적합
### MySQL이 나은 점
- 빠른 단순 쿼리 처리 속도
- 가벼운 설치와 넓은 호환성
- 커뮤니티와 레퍼런스 많음
